# 0001. iam とは別のリポジトリにする

- 状態: 承認
- 日付: 2026-11-03

## 背景

端末管理（MDM）を作る。同じ作者の iam（認証・認可）と組み合わせて使う。

## 決定

- 別のリポジトリ（`imohiyoko/mdm`）にする。iam の `docs/scope.md` で MDM は iam の外と決めているため
- 言語は iam と同じ Go。ポートとアダプタで外部の依存を切り離す作り方も iam にそろえる
- 管理者のログインは iam の OIDC、端末の準拠の状態は iam に送る（段階 6）

## 結果

- iam の範囲を広げずに済む。iam を使わない構成（管理の API の鍵だけ）でも動く
- 2 つのリポジトリの間の約束（準拠の状態の形）を文書にしておく必要がある

## 検討した代替案

- iam のフィーチャーにする（範囲の外で、iam のバイナリと権限が大きくなる）
