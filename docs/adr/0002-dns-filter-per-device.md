# 0002. 通信フィルターは端末ごとの暗号化した DNS で行う

- 状態: 承認
- 日付: 2026-11-03

## 背景

子どもの端末の通信（危ないサイト・時間帯）を管理したい。4 機種で同じように効き、MDM の登録の前からでも使えるものが要る。

## 決定

- サイトの名前を引く DNS を自前で持ち、子どもの端末をそこに向ける。暗号化した DNS（DoH、DoT）だけを受ける
- 端末は秘密で見分ける。DoH は URL のパス、DoT は TLS のホスト名（Android のプライベート DNS はホスト名しか設定できないため）。秘密はハッシュだけを保存する
- 止めた名前には NXDOMAIN と拡張エラー「Blocked」を返す
- 端末の管理に要る通信（プッシュ・時刻）は、止める時間帯でも止めない
- 子どもが設定を外せないようにするのは、各機種の MDM で設定を固定して行う（段階 3〜5）

## 結果

- 機種によらず同じルールが効き、どこにつないだかの記録が残る
- DNS を使わない通信（IP アドレスを直に使うアプリ、VPN、別の暗号化した DNS）は止められない。MDM で VPN・DNS の設定を固定して補う
- 端末の場所に関係なく効くよう、インターネットから届く場所に置く必要がある

## 検討した代替案

- 家のルーターの DNS で止める（家の外では効かない、端末ごとに分けにくい）
- 端末に VPN のアプリを入れて通信を見る（機種ごとにアプリが要り、電池と速度に響く）
- 暗号化しない DNS も受ける（端末を見分けられない、通信の途中で書き換えられる）
