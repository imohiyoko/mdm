# ロードマップ

準備が少なくて動かせるものから順に作る。Apple は証明書の準備が要るので最後にする。

| 段階 | 内容 | 状態 |
| --- | --- | --- |
| 1 土台 | 家族（人）・端末・ポリシーの記録、管理の API、操作の記録。保存は SQLite | ✅ |
| 2 通信フィルター | 端末ごとの DNS フィルター（DoH・DoT）、ブロックと許可の一覧、外部の一覧、止める時間帯、今すぐ止める、記録 | ✅ |
| 3 Android | Android Management API で登録（QR コード）、アプリの許可・禁止、フィルターの強制、ロック・初期化 | |
| 4 Windows | Windows 標準の MDM（OMA-DM）で登録、アプリの禁止、フィルターの強制、ロック・初期化 | |
| 5 iPhone・Mac | Apple の MDM（APNs）で登録、制限・フィルターの配布、ロック・初期化。監視モードの端末で強い制限 | |
| 6 IAM との連携・管理画面 | 管理者のログインを IAM（OIDC）に、端末の準拠の状態を IAM に送る、親がスマホから使える管理画面 | |

## 後で考えるもの

- 検索のセーフサーチの強制（Google・YouTube・Bing の名前を、制限付きの入り口に向ける）
- ブロックの一覧の分類（大人向け・ギャンブル・SNS など）を選ぶだけで使えるようにする
- 端末自体の利用時間の制限（メーカーの入り口でできることが少ない。Apple のスクリーンタイム・Google のファミリーリンクとの併用を案内する）
- PostgreSQL のアダプタ
