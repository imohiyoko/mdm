# ロードマップ

準備が少なくて動かせるものから順に作る。Apple は証明書の準備が要るので最後にする。

| 段階 | 内容 | 状態 |
| --- | --- | --- |
| 1 土台 | 家族（人）・端末・ポリシーの記録、管理の API、操作の記録。保存は SQLite | ✅ |
| 2 通信フィルター | 端末ごとの DNS フィルター（DoH・DoT）、ブロックと許可の一覧、外部の一覧、止める時間帯、今すぐ止める、記録 | ✅ |
| 3 組織と管理者 | 組織（家族・会社）・グループ、管理者の役割（サーバー全体・組織・見るだけ）、管理者の IAM でのログイン（イントロスペクション） | ✅ |
| 4 Android | Android Management API で登録（QR コード。会社の端末は完全管理、私物は仕事用プロファイル）、アプリの許可・禁止、フィルターの強制、ロック・初期化 | ✅ |
| 5 Windows | Windows 標準の MDM（OMA-DM）で登録、アプリの禁止、フィルターの強制、ロック・初期化 | ✅（フィルターの強制は後で） |
| 6 iPhone・Mac | Apple の MDM（APNs）で登録、制限・フィルターの配布、ロック・初期化。監視モードの端末で強い制限 | ✅（私物のユーザー登録・アプリの配布は後で） |
| 7a 準拠 | 端末の準拠の判定（OS の版・画面ロック・暗号化・報告の途切れ）と、変化の IAM への知らせ（SSF・CAEP） | ✅ |
| 7b-1 Wi-Fi の認証 | 証明書で家・会社の Wi-Fi に入る仕組み（EAP-TLS の RADIUS）、端末の証明書の発行と止めること | ✅ |
| 7b-2 配布 | Wi-Fi の設定と証明書の MDM での配布（iPhone・Mac、Windows）、VPN | ✅（VPN は後で） |
| 8a 組織の管理者が自分で使う | ルーターと IAM の受け手の API での登録 | ✅ |
| 8b サインアップ | IAM でログインした人が自分の組織を作る、管理者の招待 | ✅ |
| 8c 組織ごとの準備 | Apple の通知用の証明書を組織ごとに | ✅ |
| 8d 組織ごとの上限 | 組織ごとの上限と使っている数 | ✅ |
| 8e 管理画面 | スマホからも使える管理画面（IAM でログイン、組織の作成・招待、端末・人・グループ・管理者・ルーター・操作の記録） | ✅（ポリシーの編集・Apple の証明書の画面は後で） |
| 8f RadSec | ルーターとのあいだを TLS で守る（RADIUS over TLS）、ルーターを証明書で見分ける | ✅ |
| 8g ルールの API | AI・自動化・IaC からポリシーのルールを読み書きする口（imohiyoko/API で定義、plan・apply・版の確かめ） | ✅（ファイルを扱う CLI と GitHub Actions の例は後で） |
| 9 自動登録 | Apple Business Manager・Android のゼロタッチ・Windows Autopilot | |

## 後で考えるもの
